# 14 — The 12 Routines (paste-ready for DB: Routines + DB: Routine Steps)

**How to read the tables.** Each row is one row in `DB: Routine Steps`. `Opt` = Optional (nice, not load-bearing). `Skip-safe` = skipping it breaks nothing downstream — and saying so explicitly on the page is the point, because the usual ADHD failure is abandoning a whole routine after missing one step.

**The Minimum Version is the most important field in this document.** It's the 2–3 step version for bad days, and it's what keeps a routine alive across a bad fortnight. A routine with no minimum version is a routine you'll do for three weeks and then never again.

**Three rules behind every routine here**
1. **Nothing over 10 minutes** except Sunday Soft Reset and Re-Entry.
2. **First step is physical and tiny.** Never "decide" or "review" — always stand, open, put, drink.
3. **Every routine ends with an explicit stop**, so there's no ambiguity about whether you've finished it.

## R3 · Work Shutdown
`When:` Work shutdown · `Energy Needed:` 🪫 Low · `Minutes:` 8

> **If you only ever adopt one routine from this list, make it this one.** It's the highest-leverage routine in the whole system, because it does two things nothing else does: it prevents the open loops that keep you awake, and it removes the morning cold-start — which is where most ADHD workdays are lost.

| # | Step | Min | Opt | Skip-safe |
|---|---|---|---|---|
| 1 | Brain dump everything still in your head into the Brain Dump. Fragments only | 3 | | |
| 2 | Write tomorrow's One Thing **and its first physical action** | 2 | | |
| 3 | Any promise you made today that isn't written down → write it down now | 1 | | |
| 4 | Close the tabs. All of them. They are not a to-do list | 1 | | ✅ |
| 5 | Tidy the desk surface — 60 seconds, not properly | 1 | ✅ | ✅ |
| 6 | Say out loud: **"Work is finished for today."** | — | | |

**Minimum Version:** Brain dump. Tomorrow's One Thing. Say it's finished.

> Step 6 sounds silly and does real work: without an explicit end, work stays open in the background all evening and costs you energy you're not even using.

## R6 · Post-Meeting Dump
`When:` Work start · `Energy Needed:` 🪫 Low · `Minutes:` 3

| # | Step | Min | Opt | Skip-safe |
|---|---|---|---|---|
| 1 | **Before you do anything else**, open the Brain Dump | — | | |
| 2 | What did I agree to do? Dump each one, no formatting | 1 | | |
| 3 | What did someone else agree to do? Dump it — you'll need it later and nobody else will remember | 1 | | ✅ |
| 4 | Any date mentioned → straight into the calendar now | 1 | | |
| 5 | **Stop.** Triage later, not now | — | | |

**Minimum Version:** Dump what you agreed to do. That's it.

> Run this in the **first 90 seconds** after the meeting ends. Working memory is already dumping it — this is a race and you're losing it by default. If you go to the next thing first, it's gone, and "I'll remember the important bit" is how commitments disappear.

## Shipping notes

**What to pre-load in a new member's Desk**
- `Active` = ✅ on **three only**: R1 Morning, R3 Work Shutdown, R7 Bad Day Minimum. The other nine sit in the Library, inactive.
- Three is deliberate. A new member handed twelve active routines will do none of them; the single most common onboarding failure in products like this is enthusiastic over-adoption in week one followed by total abandonment in week three.
- The first-run page says explicitly: *"Three are switched on. Add more when these are boring. Ignore the rest."*

**The line that belongs at the top of the Routines page**
> A routine you do three times a week is working. A routine you've done once this month is still working. There is no streak here and nothing resets.

**Where the overlaps are deliberate:** R8, R9, R10 and R11 are the step-list versions of C1, C8, C2 and P5. The routine is what you run; the Vault page is where the reasoning lives. Each routine links to its full version, and that's the intended structure — don't merge them.
