# 13 — Resource Vault: The 3 Worksheets

A worksheet produces an **artefact** — a thing the member keeps and refers back to. These three are the highest-value pages in the Vault, because each one replaces a belief about personal failure with a piece of evidence about how a specific brain works.

Each becomes a row in `DB: Resources`, `Type` = Worksheet. In Notion each is a template button that creates a filled-in child page the member keeps.

---

## W1 · The Energy Audit
- **Use when:** "I want to know when my actually-good hours are instead of guessing"
- **Topic:** Health · **Minutes:** 15 to set up, 3 weeks to run · **Energy:** 🪫 Low

> **Why this is the most valuable thing in the Vault.** Almost everyone is working on a schedule inherited from school and offices — hard work in the morning, admin in the afternoon, evenings free — and almost nobody has checked whether it matches their own brain. When members find their real curve, two things happen: output goes up without any extra effort, and a great deal of guilt disappears, because hours they'd been treating as personal failures turn out to be predictable troughs.

**How to run it**
Four taps a day for three weeks. That's the whole protocol. Use the one-tap buttons on your Desk — don't write paragraphs, don't analyse as you go.

| | Morning | Midday | Afternoon | Evening |
|---|---|---|---|---|
| **Energy** 1–5 | | | | |
| **Meds?** | | | | |
| **Slept well?** | | | | |

**Do not analyse before day 14.** Early data is noise, and looking too early produces a conclusion you then unconsciously defend.

**After three weeks, answer these seven questions in writing:**

1. **My genuinely good hours are:** `_____ to _____` — the window where you scored 4–5 most often. Almost always **shorter than people expect: two to four hours**, not eight.
2. **My crash hits at:** `_____` — and it's usually within 30 minutes of the same time every day.
3. **My second wind, if I have one:** `_____` (many people have a real one in the evening; many don't, and knowing which you are is worth a lot).
4. **My worst hour of the week is:** `_____` (day + time. Monday 3pm and Sunday 6pm are the two most common answers.)
5. **Sleep changed my energy by:** `_____` — compare average score on well-slept days vs not. Most people find a bigger gap than they expected, which makes sleep a productivity intervention rather than a wellness one.
6. **What I have been scheduling in my worst window:** `_____` ← **this is the finding.** Most people discover they've been filing their hardest work into their lowest hours for years.
7. **One change I'm making:** `_____`

**The three changes that come out of this most often**
- Move your one genuinely hard task into the real good window, and protect that window like an appointment with someone intimidating.
- Stop scheduling anything cognitively demanding after the crash. Afternoons become admin, errands, body doubling, movement.
- Stop treating the crash as evidence about yourself. It's a time of day. It's on the chart.

**The side benefit, which members mention a lot:** this chart is genuinely useful to show a doctor, psychiatrist or therapist. "Here's three weeks of data" changes the quality of that conversation considerably — far more than trying to describe it from memory in a ten-minute appointment.

## W2 · The Abandonment Autopsy
- **Use when:** "I've abandoned every system I've ever tried and I want to know why before I start another one"
- **Topic:** Self-talk · **Minutes:** 25 · **Energy:** 🔋 Medium

> **Do this in week one of your membership.** It takes 25 minutes and it is the strongest predictor of whether this system survives, because it turns "I always quit" — an identity statement, and a false one — into a short list of specific, fixable mechanisms.
>
> **The frame, and it matters:** you are not auditing yourself. You are auditing the *tools*. Every one of them made a design bet about your brain and lost. We're finding out which bet each one made.

**Part 1 — The graveyard (10 min)**
List every system you've abandoned. Planners, apps, bullet journals, whiteboards, that friend's method, the thing your therapist suggested. Aim for at least four — most people get to six or seven once they start.

| System | How long it lasted | The week it died | What was happening in my life that week |
|---|---|---|---|
| | | | |
| | | | |
| | | | |
| | | | |
| | | | |

That last column is the one people skip and the one that carries the information. Look at it. **It's very often the same kind of week** — a holiday, a busy fortnight at work, an illness, a move, a bad patch. Which means these systems didn't fail at steady state; they failed at every single disruption. That's a design flaw in all of them, not a flaw in you.

**Part 2 — Cause of death (10 min)**
For each system, tick every cause that applies:

- [ ] **Setup cost** — I spent hours configuring it and never used it
- [ ] **Maintenance debt** — it went stale, then opening it felt bad, then I stopped
- [ ] **Punished inconsistency** — a broken streak, a blank page, a red overdue list made it radioactive
- [ ] **Too many decisions** — I couldn't work out where to put a thing, so I put it nowhere
- [ ] **Date-based** — everything was organised around a calendar, and I can't feel time
- [ ] **No bad-day version** — it only worked when I was already functioning
- [ ] **Novelty wore off** — it was fun for three weeks, which is how long new things are fun
- [ ] **Capture was too slow** — by the time I'd opened it and filled in the fields, the thought was gone
- [ ] **Desktop-only** — my life happens on my phone
- [ ] **A disruption** — I went away / got ill / had a bad fortnight and never came back

**Now count the columns.** Your top two or three causes will repeat across almost every system. That's your actual pattern.

**Part 3 — Your personal design brief (5 min)**
Write it out — this is the artefact you keep:

```
MY TOP THREE FAILURE MODES
1. _______________________
2. _______________________
3. _______________________

THEREFORE, ANY SYSTEM I USE MUST:
· _______________________
· _______________________
· _______________________

THE THING MOST LIKELY TO KILL MY CURRENT SYSTEM IS:
_______________________

MY EARLY WARNING SIGN (the behaviour that comes before I quit):
_______________________

WHAT I'LL DO WHEN I NOTICE IT:
Open Re-Entry. Delete ten things. Pick one 15-minute task. Tell #low-energy-days.
```

> **The line to keep:** "I always quit" is not true. What's true is "I quit systems that require maintenance I can't do, punish inconsistency, and have no version for a bad day." That's a specification, not a character flaw — and a specification can be met.

## W3 · The Accommodation Inventory
- **Use when:** "I want to know what actually helps me instead of guessing every time"
- **Topic:** Work · **Minutes:** 30 · **Energy:** 🔋 Medium

> **What this is for.** Most of us have worked out dozens of adaptations by accident over the years and never written any of them down — so every new job, flat or crisis starts from scratch. This produces one page that answers "what do I need?" in a job interview, an accommodation request, a doctor's appointment, a conversation with a partner, or at 2am when nothing is working.
>
> Fill it in on a good day. Keep it in your Desk. Update it twice a year.

### Part 1 — What already works (15 min)
Go through your actual life, not a list of best practices. The question is: *when things have gone well, what was in place?*

**Environment**
- Noise: `_______________` (silence / white noise / music with no words / a café / headphones on with nothing playing)
- Light: `_______________`
- Where I actually get work done: `_______________` (be honest — for a lot of people it's not the desk)
- Movement: `_______________` (standing, walking calls, a walk before starting)
- Temperature, clothing, shoes-on-or-off: `_______________`

**Time**
- My good hours (from W1): `_______________`
- The length of session that works: `_______________` (commonly 25–50 min, rarely 3 hours)
- What I need between tasks: `_______________`
- My hard stop: `_______________`

**Inputs**
- I retain information best as: `_______________` (written / spoken then written / diagrams / read aloud)
- Instructions must be: `_______________` (in writing, in one place, with a deadline date not "when you can")
- I lose things said to me when: `_______________` (mid-task, in meetings, on the phone with no notes)

**Activation**
- I can start when: `_______________` (someone else is present / there's a timer / the first step is physical / it's the second-most-important thing)
- I cannot start when: `_______________`
- What has reliably got me moving: `_______________`

**Recovery**
- What a bad day needs: `_______________`
- What a bad *week* needs: `_______________`
- Who I can tell: `_______________` (names. Actual names.)

### Part 2 — The asks (10 min)
Turn Part 1 into requests, each with a one-line business or practical case. Three per context, maximum.

| Context | What I need | Why it helps (the case) |
|---|---|---|
| Work | | |
| Work | | |
| Work | | |
| Home / partner | | |
| Home / partner | | |
| Medical appointments | | |

### Part 3 — The one-page summary (5 min)
This is the artefact. Keep it where you can find it in 20 seconds.

```
HOW I WORK — [name], updated [date]

I do my best work: _______________
I need instructions: _______________
I struggle most with: _______________
Three things that help enormously: _______________
What a bad day looks like, and what I need then: _______________
What I'm great at (don't skip this): _______________
```

> **Don't skip the last line.** The inventory is a list of needs, and a list of needs read back on a bad day is grim without the other half. Name two things you're genuinely good at. For a lot of people that's rapid pattern-matching, crisis performance, idea generation, or an unusual tolerance for ambiguity — the same wiring, with the costs and the benefits listed together.

**Where this gets used**
- Script **S4** (workplace accommodation) — Part 2 fills in the asks directly
- Script **S8** (explaining to a partner) — Part 3 is most of the conversation
- Script **S6** (assessment referral) — Part 1's specifics are exactly the functional-impact evidence that appointment needs
- A new job's first week — hand Part 3 to a manager and skip six months of them guessing
